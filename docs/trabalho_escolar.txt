
CONCURSO AGRINHO 2026 – PROJETO DE PROGRAMAÇÃO FRONT-END

Prezados estudantes,

Durante o segundo trimestre, desenvolveremos um projeto de programação que também poderá ser inscrito no Concurso Agrinho 2026, promovido pelo SENAR-PR e pela Secretaria de Estado da Educação do Paraná.

O tema do Concurso Agrinho 2026 é: "

Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente."
O objetivo da atividade é aplicar os conhecimentos estudados em sala de aula sobre desenvolvimento web utilizando HTML, CSS e JavaScript, criando uma solução tecnológica relacionada ao tema proposto pelo concurso.


Tema do Projeto

O projeto deverá abordar a relação entre produção agrícola, sustentabilidade ambiental, preservação dos recursos naturais e desenvolvimento tecnológico no campo.

O que deverá ser desenvolvido?

Cada estudante deverá criar um utilizando exclusivamente:
HTML;
CSS;
JavaScript.
Não será permitido o uso de:
Bootstrap;
React;
Angular;
Vue;
JQuery;
Bibliotecas externas;
Frameworks de qualquer tipo.
O projeto deverá ser desenvolvido integralmente pelo estudante.

A entrega será realizada em duas etapas obrigatórias:

1. Plataforma Alura
O estudante deverá concluir todas as atividades da unidade destinada ao Concurso Agrinho 2026 na plataforma Alura.

2. GitHub
O projeto deverá ser publicado em um repositório público no GitHub contendo:
Arquivo HTML;
Arquivo CSS;
Arquivo JavaScript;
Arquivo README.md com a descrição do projeto.
O site deverá estar funcionando através do GitHub Pages ou Vercel.

O link do repositório deverá ser enviado conforme orientações que serão disponibilizadas pelo professor.

Critérios de Avaliação
Serão avaliados os seguintes aspectos:Programação
Estrutura do código;
Organização dos arquivos;
Utilização correta de HTML, CSS e JavaScript;
Manipulação de elementos da página utilizando JavaScript.
Usabilidade
Facilidade de navegação;
Funcionamento dos botões e recursos;
Clareza das informações;
Responsividade da página.
Publicação
Organização do repositório GitHub;
README preenchido corretamente;
Site publicado e funcionando.
Originalidade
Criatividade;
Identidade visual;
Qualidade do conteúdo produzido;
Relação com o tema proposto.
Valor da Atividade

A conclusão da atividade e a entrega correta do projeto na Alura e no GitHub valerão: 30 pontos na composição da nota do 2º Trimestre.

Recuperação

Os estudantes que não atingirem o desempenho esperado ou que não realizarem a entrega dentro do prazo deverão participar da recuperação.

A recuperação consistirá no desenvolvimento e entrega do mesmo projeto, obedecendo aos mesmos critérios de avaliação.
Os estudantes em recuperação terão: 1 semana adicional para concluir e entregar o projeto.

Recomendações
Planeje seu projeto com antecedência;
Faça entregas parciais durante o desenvolvimento;
Teste o funcionamento do site frequentemente;
Organize corretamente seus arquivos;
Evite copiar projetos da internet;
Produza conteúdo autoral sempre que possível.
IMPORTANTE!
A unidade curricular ofertada na plataforma Alura, "Agrinho 2026 - Categoria Desenvolvimento Front-End" traz orientações em 4 Aulas que deverão estar concluídas até o dia 14/06. O link para acessar as aulas é: 

https://cursos.alura.com.br/course/agrinho-2026-categoria-desenvolvimento-front-end

O documento anexo a esta atividade deverá ser preenchido até o dia 08/06 pois utilizaremos ele para criar os arquivos HTML, CSS e JS.
Lembre-se: além de compor sua nota do trimestre, seu projeto poderá representar nossa escola no Concurso Agrinho 2026.
